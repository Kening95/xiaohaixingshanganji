# 《小海星上岸记》3 步上线部署指引（Vercel 免费版）

> 适合人群：完全没接触过服务器、没部署过网站的小白。
> 照着做 15~20 分钟，就能把项目传到网上，拿到一个公开链接（例如 `https://xxx.vercel.app`），
> 手机、电脑、微信里都能直接打开。

---

## 开始前准备（一次性，2 分钟）

只需要注册两个免费账号（都有中文页面）：

1. **GitHub**（存代码用）：打开 <https://github.com> → Sign up → 用邮箱注册，免费。
2. **Vercel**（托管网站用）：打开 <https://vercel.com> → Sign Up →
   **选 "Continue with GitHub"** 用刚注册的 GitHub 账号一键登录（两边账号关联，后面省一步）。

---

## 第 1 步：把项目代码传到 GitHub（约 5 分钟）

1. 打开 GitHub 网站，右上角点 **「+」→「New repository」（新建仓库）**。
2. 仓库名填 `xiaohaixing-shanganji`（随意，英文小写即可），选 **Public（公开）**，
   其他都别动，点 **「Create repository」**。
3. 创建后会看到一个提示页面，先放着不管。
4. 在自己电脑上打开项目文件夹：
   `D:\KimiData\kimi\Workspaces\粉蹄闯关记网页开发\粉蹄闯关记`
5. 在文件夹地址栏输入 `cmd` 回车（打开黑色命令窗口），然后**逐行**粘贴执行下面命令
   （把 `你的用户名` 换成 GitHub 用户名）：

   ```bat
   git init
   git add .
   git commit -m "首次上传：小海星上岸记"
   git branch -M main
   git remote add origin https://github.com/你的用户名/xiaohaixing-shanganji.git
   git push -u origin main
   ```

6. 第一次 push 会弹出登录窗口 → 选 **「Sign in with your browser」** 浏览器授权即可。
7. 看到 `main -> main` 字样 = 上传成功。回到 GitHub 网页刷新，能看到所有文件。

> 📌 本项目已自带 `.gitignore`，`node_modules`（几百 MB 的依赖）和 `dist`（构建产物）
> 不会上传，仓库体积很小，GitHub 不会拒收。

---

## 第 2 步：在 Vercel 一键导入并部署（约 3 分钟）

1. 登录 <https://vercel.com>，点 **「Add New…」→「Project」**。
2. 点 **「Import Git Repository」** 里你刚传的 `xiaohaixing-shanganji` 旁边的 **「Import」**。
3. 配置页面**什么都不要改**（本项目已内置 `vercel.json`，Vercel 会自动识别）：
   - Framework Preset 会自动识别成 Vite ✅
   - Build Command 会自动填 `vite build` ✅
4. 直接点最下方 **「Deploy」**。
5. 等 1~2 分钟，出现 🎉 **「Congratulations!」** = 部署成功！
   页面上 `https://xxx.vercel.app` 就是你的公开网址，点进去就能玩。

> 📌 以后每次改进：只要在本地执行 `git add . && git commit -m "说明" && git push`，
> Vercel 检测到代码变化会**自动重新部署**，1~2 分钟后网站自动更新，什么都不用点。

---

## 第 3 步：开通云端数据同步 + 备份（约 5 分钟，强烈建议）

不配这一步网站也能玩，但学习数据只存在用户自己浏览器里（换设备/清缓存会丢）。
配好后：用户任何操作 3 秒内自动备份到云端，换手机换电脑登录后数据自动恢复。

1. Vercel 项目页顶部点 **「Storage」→「Create Database」→ 选「KV」**。
2. 名字随意（如 `shanganji-kv`），区域选 **Singapore（新加坡，离中国最近）**，点 **「Create」**。
3. 创建后会问 **「Connect to Project」**：选你的项目，两个环境（Production / Preview）
   都勾选，点 **「Connect」**。（就是把数据库和网站连起来）
4. 进项目 **「Settings」→「Environment Variables」**，新增一个变量：

   | 名称（Key） | 值（Value） |
   |---|---|
   | `VITE_SYNC_ENDPOINT` | `https://你的网址.vercel.app/api/sync` |

   （把网址换成第 2 步拿到的真实链接，注意是 `https` 开头）
5. 关键一步：回项目页点 **「Deployments」→ 最新一条右边「⋯」→「Redeploy」**。
   ⚠️ 必须重新部署一次！因为前端代码是在构建时把同步地址写死的，不重新部署不生效。

### 验证同步是否成功

打开网站 → 登录（手机号验证码演示码 888888）→ 个人中心看「同步状态」显示已同步 ✅；
勾选任意任务等 3 秒 → 刷新页面数据还在 = 云端备份生效。
